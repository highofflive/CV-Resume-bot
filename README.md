# 📄 CV Generator Telegram Bot

Telegram-бот для швидкого створення, збереження та генерації структурованого резюме (CV) у форматі PDF. Проєкт побудований за модульною архітектурою з розділенням бізнес-логіки, інтерфейсу та шару роботи з базою даних.

## 🚀 Основний функціонал

* **Покрокове опитування (5 етапів):** збір даних про кандидата (ім'я, бажана посада, контакти, навички, досвід та освіта) з валідацією введення та підтримкою команди `/cancel`.
* **Збереження та оновлення даних:** автоматичний запис анкети в базу даних з можливістю перегляду збереженого резюме та його перезапису.
* **Генерація PDF на льоту:** створення охайного PDF-документа з підтримкою кирилиці та автоматичним видаленням тимчасових файлів після відправки користувачу.
* **Готовність до масштабування:** використання ORM дозволяє перейти з SQLite на PostgreSQL зміною одного рядка конфігурації.

## 🛠 Технологічний стек

* **Мова:** Python 3.12+
* **Telegram API:** `pyTelegramBotAPI` (`telebot`)
* **База даних та ORM:** `SQLAlchemy 2.0` (SQLite за замовчуванням, сумісність із PostgreSQL)
* **Генерація PDF:** `fpdf2` (кастомні TrueType-шрифти `Arial` для коректного рендерингу кирилиці)
* **Конфігурація та залежності:** `uv`, `python-dotenv`

## 📂 Структура проєкту

```text
├── app/
│   ├── main.py          # Точка входу, обробники команд/кнопок та сценарій опитування
│   ├── database.py      # Підключення до БД, ORM-модель CV та фабрика сесій
│   ├── keyboards.py     # Inline-клавіатури бота
│   ├── texts.py         # Шаблони повідомлень, запитання анкети та форматування
│   └── pdf_maker.py     # Логіка верстки та генерації PDF-файлу
├── arial.ttf            # Шрифт для основного тексту PDF
├── arialbd.ttf          # Жирний шрифт для заголовків PDF
├── .env                 # Змінні оточення (не відстежується Git)
├── pyproject.toml       # Залежності проєкту
└── uv.lock              # Фіксовані версії пакетів
```
